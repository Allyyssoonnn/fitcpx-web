- Opção [Sair da conta] - Sai da conta e volta para tela de login do sistema

* Barra lateral do app

- Opção [Enviar feedback] - Opção para enviar feedback e sugestões para melhoria do sistema
- [Novo feedback]
- Selecionar assunto do feedback e preencher comentário abaixo

- Aba [Conta]

Autenticação


* Tela de login - Primeira tela conhecida pelo usuário para entrar no sistema

- [REMOVER] Opção (Lembrar de mim) - ao marcar cliente permanecerá logado no sistema mesmo se fechar a página
- Opção (Esqueceu a senha?) - Ao clicar o usuário é levado a tela de recuperação de senha
- Opção (Conectar conta google) - Ao clicar o usuário é levado a selecionar uma conta google para realizar login utilizando a conta da google selecionada
- Opção (Criar conta) - Caso o cliente não tenha se registrado anteriormente

* [REVISAR] Tela de recuperação de senha - Destinada a ajudar o cliente recuperar sua senha de acesso

- Digitar E-mail para envio do E-mail de recuperação


* Tela de registro - Tela dedicada para o registro do usuário

- Usuário precisa preencher [Nome, E-mail, Senha, Repetir Senha]
- Aceitar os termos de uso do sistema para registrar, clicando em (Termos e condições) será exibido o texto

- [E-MAIL] - É enviado um E-mail com código de confirmação do cadastro


App

* Tela Inicio - Primeira tela que o usuário vê no primeiro contato dentro do sistema

- Bloco últimas avaliações - Exibe as últimas 7 avaliações realizadas dentro do sistema - [Aluno, Data, Altura, Peso]
- Bloco resumo empresa - Exibe total de [Alunos ativos, Avaliações realizadas, Treinos prescritos, Usuários ativos]
- Ao se cadastrar também é exibido card de confirmação de E-mail pelo código enviado ao se registrar [Código de 4 Dígitos]
- Também é onde aparecerão avisos

* Tela da Agenda - Destinado a calendário de eventos marcados e disponibilidade de horários

- Opções de avançar e retroceder meses (Ícone de setas)
- Opção (Novo evento) - Para cadastrar um novo evento ou disponibilidade de horário
- A seguir opções de visualização (Mês, Semana e Dia)
- Abaixo calendário com marcações dos eventos ou disponibilidades
- [NOVO EVENTO]
- Tipo do evento (Evento, disponibilidade)
- Preenchendo os demais campos é possível cadastrar um novo item no calendário

- [E-MAIL] - Um E-mail é enviado para o aluno com o novo evento

* Telas avaliações - Lista de todas avaliações realizadas no sistema

- Opção campo de busca, para filtrar por texto

* Treinar o aluno - Destinada a acompanhar o treino em tempo real do aluno

- Selecionar os alunos que irão treinar até 15 alunos
- Opção abrir planilha vai levar para o treino em tempo real
- Nessa tela é possível alternar entre alunos e editar o treino em tempo real enquanto realiza o treino

ALUNO

* Tela de Alunos - Lista de alunos cadastrados no sistema

- Opção de pesquisa - Digitando nome ou parte do nome do aluno a lista será filtrada em tempo real
- Opção de filtro ao lado da caixa de pesquisa - Abre um card de filtros disponíveis para essa lista selecionados o filtro já é realizado em tempo real
- Opção (Novo aluno) - Essa opção leva a tela de cadastro de um novo aluno
- Ao clicar no registro do aluno será levado para a (Visualização do aluno)
- [FILTROS]
- Deletados - Alunos deletados do sistema que podem ser recuperados
- Status do aluno - [Ativo, Inativo, Bloqueado]
- [OPÇÕES REGISTROS]
- Em cada aluno da lista no final do registro (Mais opções [3 Pontos])
- [EDITAR] - Essa opção leva para tela de edição do aluno e seus dados
- [EXCLUIR] - Essa opção deleta o aluno tornando, não será listado a menos que filtre por alunos deletados
- [RECUPERAR] - Essa opção recupera um aluno excluído

* Cadastro de aluno - Tela destinada a colher os dados do novo aluno

- Campos obrigatório estão marcados com um (*) na frente do nome
- Ao preencher confirmar e o aluno estará cadastrados

* Tela de visualização do aluno - Tela destinada a exibir informações básicas do aluno selecionado e acesso a seus registros

- Opção de (FOTO) para carregar ou atualizar foto de perfil do aluno
- Opção (Editar perfil) - Essa opção leva também para a edição dos dados do aluno
- Opção (Desativar) e (Ativar) - Essa opção ativa ou desativa o aluno e isso corta o acesso do aluno ao app
- [ABAS DE REGISTRO] - Todas as abas tem uma opção de cadastrar novo registro
- [INFORMAÇÕES PESSOAIS] - Informações básicas do aluno (Contato e endereço)
- [AVALIAÇÃO FÍSICA] - Lista de avaliações realizadas neste aluno - [Opção para editar a avaliação e ver resultado da avaliação física]
- [TREINOS] - Lista de treinos prescritos para esse aluno - [Opção para editar treino e (Desativar ou Ativa) o treino - Treinos desativados não são exibidos no app do aluno]
- [OPÇÃO NOVO TREINO] - Essa opção tem 3 possibilidades
- * [NOVO TREINO] - Criar um treino totalmente do zero
- * [IMPORTAR BASE] - Criar um treino baseado em algum treino já pré cadastrado anteriormente
- * [REAJUSTE] - Criar um treino baseado em um dos treinos anteriores do aluno
- [CONTRATOS] - Lista de contratos vinculados a esse aluno

* Tela de visualização do resultado da avaliação física - Tela para visualização da avaliação física realizada

- Opção voltar retorna para tela anterior
- Opção (Comparar) leva para tela de comparação de avaliação física
- Abaixo fica os blocos referentes a cada informação da avaliação física
- Gráficos disponíveis

* Tela de comparação resultado avaliação física - Tela de comparação para acompanhar evolução do aluno em 3 avaliações

- Opção voltar retorna para tela anterior
- Seleção da avaliações - Somente 3 avaliações são permitidas para visualização da comparação
- Blocos para visualização dos dados e gráficos disponíveis
- No último bloco é possível selecionar 2 ou 3 Fotos para comparação

* Tela de cadastro de avaliação física - Tela para cadastro do registro de uma avaliação física

- Opção voltar retorna para tela anterior
- Opção (Limpar) zera todos os campos preenchidos
- Primeira etapa para informações gerais sobre o aluno
- Abaixo separado em abas cada etapa da avaliação física [Bioimpedância, Diâmetros, Dobras cutâneas, Perímetros, Imagens]
- Alguns campos tem a opção de preencher o dado com a informação da avaliação anterior
- Alguns campos tem a opção com microfone para dizer a medida para preenchimento automático

* Tela de cadastro de treino

- Opção voltar retorna para tela anterior
- Primeira etapa para informações gerais sobre o treino
- No segundo bloco está a prescrição do treino
- Opção (Adicionar sessão) - Essa opção adiciona uma sessão de treino se limitando a 15 sessões por prescrição
- [LISTA DE SESSÕES]
- Na borda esquerda da sessão é possível arrastar o bloco todo para mudar a sequência da mesma
- Opção (Ícone de Lâmpada) se trata da prescrição inteligente de toda sessão de treino
- Opção (Ícone de lápis) se trata da edição do nome podendo ser editada para (Segunda, Terça) ou (Superior, Inferior) aberto para texto
- Opção (Ícone de lixeira) - serve para excluir a sessão do seu treino
- Opção (Adicionar exercício) - Adiciona um novo exercício a sua sessão
- [PRESCRIÇÃO INTELIGENTE]
- Ao abrir a prescrição inteligente você deverá selecionar todos os grupos musculares que farão parte desse treinamento
- Seguido da informação do total de séries para o grupo selecionado
- Na segunda etapa você vai selecionar o desenvolvimento do treino
- Abaixo a seleção de dores relatadas pelo aluno caso houver
- Abaixo a seleção de equipamentos não disponíveis
- Por último o tempo total de treino pretendido
- Opção [PRESETS] permite salvar as informações preenchidas para não precisar informar novamente
- [LISTA DE EXERCÍCIOS]
- Primeira opção de mover a sequência do exercício assim como na sessão
- Opção (Ícone de funil) - se trata dos filtros para melhor seleção do exercício adequado, a confirmar o filtro a lista de exercícios disponíveis é filtrada
- O Select a seguir serve para selecionar o exercício
- [Opção (Ícone de 3 pontos)]
- Opção (Bi-set, Tri-set ou Super-set) para adicionar um exercícios vinculado ao exercício pai formando sets de treino
- Opção remover para eliminar o exercício da lista
- Abaixo do bloco do exercício seguem as opções de quantidade (Séries, Execuções, Carga, Intervalo e Observação)

- [E-MAIL] - Um E-mail com novo treino é enviado para o aluno

* Tela de cadastro de contrato - Venda de plano

- Opção voltar retorna para tela anterior
- Primeiro bloco exibe dados do contratante e do contratado
- No bloco de plano é possível alternar entre plano já cadastrado ou montar na hora
- Ao lado o bloco de resumo da compra e valor total do contrato
- Montando plano selecione a modalidade e sua variação de preço escalável caso tenha
- Abaixo selecione a duração do plano
- Abaixo selecione a data de inicio do contrato e vencimento da primeira cobrança - Ambos mesmo campo
- Abaixo selecione se vai gerar o contrato para respaldo jurídico enviando assim para assinatura do aluno pelo e-mail
- Caso exista selecione o modelo de contrato que já deve ter sido cadastrado anteriormente
- Ao lado do modelo de contrato opção para selecionar os serviços prestados que serão listados no contrato
- Após isso confirme o contrato se está tudo ok
- [PAGAMENTO]
- Opção (Receber pagamento pelo app?) - Caso marcada o sistema irá gerar a cobrança e controlar todos os recebimentos
- Abaixo forma de pagamento (Boleto, PIX e cartão)
- Abaixo modalidade de pagamento (Recorrente ou á vista) podendo ser parcelado
- Caso parcelado selecione o número de parcelas

- O contrato é enviado e gerenciado pelo AUTENTIQUE
- As cobranças são enviadas e gerenciadas pelo ASAAS
- [E-MAIL] - Um E-mail com contrato é enviado para o aluno
- [E-MAIL] - Um E-mail com cobrança é enviado para o aluno

* Tela de contratação de plano e serviços

- Aqui você pode selecionar um plano previamente cadastro ou selecionar a opção de montar plano
- Ao cadastrar você adiciona as modalidades e suas variações
- Data de inicio que tambem sera o vencimento da primeira cobrança
- Livre para editar o valor da modalidade de última hora caso necessário
- E selecionar a duração do plano
- Abaixo selecione o modelo de contrato e a descrição dos serviços prestados para montar o contrato para assinatura
